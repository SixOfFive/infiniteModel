# InfiniteModel runtime payload manifest — the AUTHORITATIVE allowlist of files
# that ship inside a package. build.sh copies ONLY these into _payload/.
#
# An allowlist (not a blacklist) is deliberate: it is the safety boundary that
# keeps secrets and dev cruft out of a PUBLIC package. Nothing here may be a
# secret, a fleet-specific preset, or generated state. Specifically NEVER add:
#   hf_token.txt                (HF API token — a secret; git-ignored anyway)
#   im_*.json                   (personal fleet model-load presets)
#   *_history.json, *_state.json, node_config.json, engine_config.json,
#     deleted_models.json, custom_gguf.json, .last_update.json  (runtime state)
#   scratch_*.py, test_*.py, bench_*.py, *_e2e.py, tp_bench.py, replica_bench.py,
#     diag_net.py, load_verify.py, validate_vram_plan.py       (dev/bench tools)
#   *.wav, *.png, *.log, __pycache__, .venv, cache/, models/
#
# How this list was derived: the static import closure of server.py (controller)
# and client.py (worker) over the repo's own modules, PLUS the two converter
# scripts invoked as subprocesses (gguf_convert.py, mxfp4_convert.py), which the
# runtime hard-errors without. Recompute with: packaging/tools/closure.py.
#
# config.json ships as the public default (no secrets; controller_host=auto).
# custom_models.json is SEEDED EMPTY ({}) by build.sh, never copied from the
# repo (the repo copy carries a personal entry) — so it is not listed here.
